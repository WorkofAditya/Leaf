    Command map

    All Leaf CLI functions available from this site

    leaf init

    Create a new Leaf repository.

    leaf status

    Inspect branch and working-tree state.

    leaf add <path>

    Stage file contents in the index.

    leaf save "message"

    Create a snapshot or diff commit.

    leaf log

    Review current branch or HEAD ancestry.

    leaf diff [commit]

    Compare a commit with the working tree.

    leaf restore <commit>

    Rebuild a commit into the workspace.

    leaf branch [name] [commit]

    List or create branch pointers.

    leaf checkout <branch>

    Switch to a branch and restore its state.

    leaf merge <branch>

    Merge another branch into the current one.

    leaf tag [name] [commit]

    Create or list lightweight tags.

    leaf reset [--soft|--hard] [commit]

    Unstage paths or move branch pointers.

    leaf revert <commit>

    Save a commit that reverses another.

    leaf ignore <path>

    Exclude generated or sensitive paths.

    leaf remote ...

    Manage local path remotes.

    leaf fetch <remote>

    Fetch commits and branch pointers.

    leaf pull <remote> <branch>

    Fetch then merge a remote branch.

    leaf push <remote> <branch>

    Copy local history to a remote repository.

    leaf clone <source> [dest]

    Create a working copy from another Leaf repo.

    leaf fsck

    Validate commits, parents, branches, and tags.

    leaf version

    Show the installed Leaf version.

    leaf help

    Display command usage guidance.
